# ChatGPT visualization catalog

The public catalog at `/apps/chatgpt` lets visitors try 17 interactive fictional examples. These cover two-period screen-time comparison, paired attention heatmaps, activity and sleep, WHOOP sessions, daily sleep/screen-time alignment, two-hour pre-sleep usage, WHOOP sleep performance, recorded locations, both heart-rate overlays, monthly attention, experiment reviews and hourly patterns, coaching suggestions, recording coverage, selected-chart context, and reflections.

The examples are generated deterministically in `core/chatgpt-catalog.js` and rendered with the app’s actual HTML/JavaScript clients. They include observed values and deliberate gaps, and remain fixed to October 2026. The gallery shows compact SVG thumbnails derived from the same fixtures; no embedded app, full fixture JSON or map tiles load until a visitor opens a card. Native card links open the full focused interactive view, and its return link targets the original card. Focused views automatically fit their full content, including expanded details, and shrink again on reset or drilldown. Sandboxed children report their content height through validated size notifications; same-origin privileges remain disabled. Categories filter the gallery; focus links render one wider example; reset restores its original state. Source/day/app/hour/point/sample controls operate on the loaded fixture. In connected ChatGPT, the corresponding real-data tools retain their existing authorization and billing.

`get_public_visualization_catalog` returns the same public content as `/apps/chatgpt/catalog.json`. Select `exampleId` in MCP or `example` over HTTP. MCP `includeData: true` corresponds to HTTP `includeData=1`; default summaries carry data null. Full data is the exact renderer input, including unknowns, source separation, matching offsets and provenance. `/apps/chatgpt.md` supplies a readable catalog. These are public examples, not a person’s available records.

Preview iframes allow scripts without same-origin privileges. Their nonce-based script CSP blocks arbitrary network connections, forms and external scripts. Only the two fictional location-map previews permit tile images from the public myself.md tile endpoint, with visible OpenStreetMap attribution. The endpoint permits only zoom levels 8–17 intersecting the fictional San Juan extent, identifies the application and catalog referrer to OpenStreetMap, caches successful images for seven days and shares the public read limiter. Markers use Web Mercator projection and retain exact point/sample details; zoom and fit use only the loaded fictional coordinates. Tile failures leave markers and details available. The real connected cards keep their existing coordinate plots. A small public host supplies fixtures through the existing app protocol and rejects account/tool requests locally. Public previews have no account transport, phone access or export allowance. Connected-account controls and date-changing presets are hidden in previews; ordinary visualization drilldowns remain interactive.

Run `npm run verify:chatgpt-catalog` for HTTP/MCP and Chromium verification. The dashboard build regenerates the host client. The full Worker suite includes anonymous HTML/JSON/preview delivery and public MCP parity under the production runtime.
