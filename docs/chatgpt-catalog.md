# ChatGPT visualization catalog

The public catalog at `/apps/chatgpt` lets visitors try six interactive fictional examples: two-period screen-time comparison, paired attention heatmaps, activity and sleep, recorded locations, heart rate over locations, and heart rate over screen-time hours.

The examples are generated deterministically in `core/chatgpt-catalog.js` and rendered with the app’s actual HTML/JavaScript clients. They include observed values and deliberate gaps, and remain fixed to October 2026. Previews automatically fit their full content, including expanded details, and shrink again on reset or drilldown. Sandboxed children report their content height through validated size notifications; same-origin privileges remain disabled. Categories filter the gallery; focus links render one wider example; reset restores its original state. Source/day/app/hour/point/sample controls operate on the loaded fixture. In connected ChatGPT, the corresponding real-data tools retain their existing authorization and billing.

`get_public_visualization_catalog` returns the same public content as `/apps/chatgpt/catalog.json`. Select `exampleId` in MCP or `example` over HTTP. MCP `includeData: true` corresponds to HTTP `includeData=1`; default summaries carry data null. Full data is the exact renderer input, including unknowns, source separation, matching offsets and provenance. `/apps/chatgpt.md` supplies a readable catalog. These are public examples, not a person’s available records.

Preview iframes allow scripts without same-origin privileges. Their nonce-based script CSP blocks network connections, forms and external resources. A small public host supplies fixtures through the existing app protocol and rejects account/tool requests locally. Public previews have no account transport, phone access or export allowance. Connected-account controls and date-changing presets are hidden in previews; ordinary visualization drilldowns remain interactive.

Run `npm run verify:chatgpt-catalog` for HTTP/MCP and Chromium verification. The dashboard build regenerates the host client. The full Worker suite includes anonymous HTML/JSON/preview delivery and public MCP parity under the production runtime. Screenshots and scoped release evidence are stored under ignored `.local/chatgpt-catalog-release/`.
